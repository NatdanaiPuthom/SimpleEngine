How to run

Clone/Fork the repository.
Have Visual Studio 2026 ready.
Run generate_project.bat
Open newly generated SimpleEngine.slnx.
Build/Rebuild the project. (Depending on the configuration, the folder will be created as Debug, Release or Retail where .exe will be. Example Bin/Debug/SimpleEngine_Debug.exe)
Run Local Windows Debugger or .exe from Bin.
Hardware specifications:

Windows 11 64-bit
NVIDIA RTX3060 & RTX3070 (DirectX12)
AMD Ryzen 5 Processor
Intel 9th Generation Processor

: Any other hardware is not tested
